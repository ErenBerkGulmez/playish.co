# playish.co

League of Legends maçlarını otomatik kaydeden ve kayıtlardan klip kesmenizi sağlayan Windows uygulaması.

## İndir

En güncel kurulum dosyası: **[Releases › Latest](https://github.com/ErenBerkGulmez/playish.co/releases/latest)**

`playish.co_x.y.z_x64-setup.exe` dosyasını indirip çalıştırın. Uygulama açılışta yeni sürümleri kendisi denetler ve güncelleme çıktığında haber verir.

## Gereksinimler

- Windows 10 / 11 (64 bit)
- Ekran kartı kodlayıcısı önerilir (NVIDIA NVENC ile test edilmiştir)

## Üçüncü taraf yazılım

Kurulum paketi, video işleme için [FFmpeg](https://ffmpeg.org) içerir (gyan.dev "essentials" derlemesi, GPLv3).
FFmpeg ayrı bir program olarak çalıştırılır; kaynak kodu ve lisansı için: https://ffmpeg.org/download.html ve https://www.gyan.dev/ffmpeg/builds/
